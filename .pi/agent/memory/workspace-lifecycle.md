---
name: workspace-lifecycle
description: Workspace lease and collection invariants discovered during manual validation.
category: architecture
---

A no-change `workspace_results` row may outlive the lease that created it. Reset, discard, and verified no-change release must rebase the reusable worktree and stored `base_revision` to the current parent HEAD; otherwise a later worker can run against stale source. Reconciliation must only release a task lease when `latestResult.runId === workspace.leaseRunId`; otherwise a new task lease can be released because of an older result. Collection must consume the retained agent result before releasing a no-change lease, so failed collection cannot strand an unleased retained run. Manual workspace collection flows must use `agent(action="start", background=true, isolation="worktree")`; foreground `start` results are returned directly and are not collectable. Foreground isolated `start`/`continue`/explicit cancellation must therefore prepare the workspace result directly, releasing verified no-change leases or retaining changed leases for disposition. `/agents` browsing runs the same safe no-change reconciliation; changed/uncertain leases remain protected. A lease with any matching catalog row is known, including terminal runs whose prepared result still awaits disposition; only a missing catalog row is orphaned. Parent agent actions can inspect, apply, discard, or continue prepared isolated results; continuation starts a new worker in the same leased workspace. Past persisted startup/running metadata is displayed as interrupted because no live child handle is attached to a past transcript. Workspace browser actions must compare both lease ownership and `latestResult.runId === leaseRunId`: apply/retain remain owner-bound, while reset/discard may manually clear an inactive task lease from another session. Durable active task leases and setup leases remain protected; orphan recovery remains available. A historical result must not suppress stale-lease release. Reset returns a freshly reloaded workspace row so cleared lease state and discarded-result status are projected immediately.
